# 四维评审标准

所有成功率以唯一有效 `case_id` 为分母。失败下载、无输入图或映射错误单独报告，不混入主观审美通过率。

## 1. 差异化

检查构图、主体位置/尺度、留白方向、色彩子方案、装饰节奏和单/双图策略。大多数图共享同一骨架、颜色坍缩、徽章机械重复或镜像复制主体，都属于失败迹象。

建议门槛：至少 80% 样本符合预设的不同分发策略，且任一单一构图簇不超过 35%。若无法可靠聚类，报告“模板化高风险”，不要伪造精确数值。

## 2. 美观度

判断设计关系：主体与标题层级、版式骨架、留白意图、材质光影、边缘透视、装饰作用、主题转译与克制。主体错误、严重遮挡/裁切、矩形抠图边、塑料感、随机装饰、明显失衡均为硬失败。

建议可用率门槛 85%，严重缺陷不超过 5%。

## 3. 乱码与文字

检查必显文字是否原文出现，是否有错字、乱码、伪英文、假拼音、无意义小字、生产元词，或虚构价格/优惠/认证/年份/地址/电话。“看起来像字但不可读”也算失败。

建议主标题准确率至少 95%；任何虚构价格或品牌为零容忍。

## 4. 商家信息与参考商品

优先级：参考商品图 > 品类 > 商家/商品原文 > 风格指令。

检查商家/门店/商品名是否来自数据集，主体是否保留品类、形态、颜色、材质与数量，双图是否被合理使用，是否虚构 Logo、品牌、卖点或经营事实。只有输入链路有效时才能评价此维度。

建议商家事实准确率至少 95%；错误商家、错误品类、虚构品牌为零容忍。

## 5. 问题频率

| 比例 | 级别 |
|---:|---|
| 70%–100% | 普遍问题 |
| 40%–69% | 高频问题 |
| 15%–39% | 中频问题 |
| 1%–14% | 偶发问题 |

## 6. 成功判定

- 四个维度都达到门槛才判 `PASS`。
- 美观优秀但商家事实错误，仍判失败。
- 差异化不足但其他维度通过，判“可用但批量模板化风险高”。
- 证据不足时判 `INSUFFICIENT_EVIDENCE`，不猜成功率。

## 7. 证据图选择

每个问题至少放一张全批总览、2–4 张代表性输入输出对比图；如有成功样本，再放 1 张边界样本。避免只挑最差图或用最佳图代表整批。
